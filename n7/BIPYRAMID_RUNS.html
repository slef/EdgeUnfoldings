An ordered run of inward patches unfolds safely

A whole run of inward patches: one ordering test

13 September 2026 · A proved family inside the remaining three- and four-inward cases. The following theorem allows any number of consecutive inward patches in a convex bipyramid. It gives an explicit sufficient rule, not a claim that some pole always passes that rule.

The whole pentagonal bipyramid remains open. The complete class count stays 7/15. This theorem supplies additional proved parts of the consecutive three-inward class BBBCC and four-inward class BBBBC.

Overview · Final two-inward proof · Radial lemmas

1. A rule that scales with the length of the run

Suppose Q0,…,Qk−1Q_0,\ldots,Q_{k-1} are inward and all point forward. Every remaining patch is convex. Let the ring have m≥k+1m\ge k+1 vertices. Choose a fan pole pp, and let

θi=∑j<iωjp,Ei=θi+1+ℓip(0≤i<k).\theta_i=\sum_{j<i}\omega_j^p, \qquad E_i=\theta_{i+1}+\ell_i^p\quad(0\le i<k).

The angle EiE_i is where inward patch ii ends around that pole. Its whole angular cone is [θi,Ei][\theta_i,E_i].

Theorem Ordered Run. If

E0≤E1≤⋯≤Ek−1≤θk+1,E_0\le E_1\le\cdots\le E_{k-1}\le\theta_{k+1},

then cutting the other pole’s edge star and the edge pu0pu_0 gives a nonoverlapping original-edge unfolding.

In ordinary language: the bad patches end in the same order in which they begin, and the last one does not pass its first convex neighbor. The test is just

ℓip≤ωi+1p+ℓi+1p(0≤i<k−1),ℓk−1p≤ωkp.\ell_i^p\le\omega_{i+1}^p+\ell_{i+1}^p\quad(0\le i<k-1), \qquad \ell_{k-1}^p\le\omega_k^p.

There is no pole-curvature ranking, curvature threshold, or planar-equator assumption. All the weak inequalities, including equality, are allowed. Reflection gives the corresponding backward-run theorem.

2. Filling an inward patch without harming its predecessor

Let PiP_i be the source copy in patch QiQ_i, and write

Hi=conv{p,ui,Pi}.H_i=\operatorname{conv}\{p,u_i,P_i\}.

This is the outer triangle containing the bad patch; its inward vertex ui+1u_{i+1} is strictly inside HiH_i.

The preceding patch Qi−1Q_{i-1} is safe against the entire triangle HiH_i. At their shared, uncut vertex uiu_i, the angular corner of HiH_i is exactly the corner occupied by the two faces of QiQ_i. Those sectors and the preceding patch’s sectors have total angle below 2π2\pi. Filling the missing triangle at the far endpoint adds no angular sector at the shared endpoint.

There is also a clipping observation. The convex triangle Hi+1H_{i+1} contains pp and is safe against QiQ_i. Where an interior point of Hi+1H_{i+1} lies inside QiQ_i’s angular cone, the radial segment from pp to it cannot cross the cut side ui+1Piu_{i+1}P_i into the bad petal. Consequently that portion of Hi+1H_{i+1} lies inside HiH_i. This is the same clipped-receiver argument, with an outer triangle in place of the final convex patch.

Only interior overlap is being tested. A boundary ray touching a cone does not need a separate strict containment assertion.

3. Propagate the separation along the run

Fix ii. The adjacent-vertex argument gives that QiQ_i is safe against Hi+1H_{i+1}. Suppose it has already been shown safe against HjH_j. Any possible interior overlap with Hj+1H_{j+1} has angle below Ei≤EjE_i\le E_j and above θj+1>θj\theta_{j+1}>\theta_j. It therefore lies inside the angular cone of QjQ_j. The clipping observation puts that overlap inside HjH_j, a contradiction.

By induction, QiQ_i is safe against every later outer triangle HjH_j. Since Qj⊂HjQ_j\subset H_j, all pairs of inward patches are safe.

The first convex patch QkQ_k is safe against its adjacent predecessor Qk−1Q_{k-1}. For an earlier QiQ_i, any possible overlap with QkQ_k lies in the cone of Qk−1Q_{k-1} because Ei≤Ek−1E_i\le E_{k-1}. The same clipping argument places it inside Hk−1H_{k-1}, already safe against QiQ_i. Thus every bad patch is safe against QkQ_k as well.

Finally, Ei≤Ek−1≤θk+1E_i\le E_{k-1}\le\theta_{k+1} prevents every bad patch from reaching any later convex patch. Those convex patches have disjoint fan wedges. There is no extension across the slit before Q0Q_0. This checks every face pair and proves the theorem for any run length.

4. Precisely what is missing for a whole three-inward class

For a three-patch forward run, define the three margins

G0p=ω1p+ℓ1p−ℓ0p,G1p=ω2p+ℓ2p−ℓ1p,G2p=ω3p−ℓ2p.G_0^p=\omega_1^p+\ell_1^p-\ell_0^p, \quad G_1^p=\omega_2^p+\ell_2^p-\ell_1^p, \quad G_2^p=\omega_3^p-\ell_2^p.

The theorem applies if either pole makes all three margins nonnegative. The adjacent corner identities give

G0p+G0q=κu1>0,G1p+G1q=κu2>0,G2p+G2q>0.G_0^p+G_0^q=\kappa_{u_1}>0,\qquad G_1^p+G_1^q=\kappa_{u_2}>0,\qquad G_2^p+G_2^q>0.

Thus no individual comparison can fail at both poles. What is still missing is a proof that a single pole can be used, or a repair when different comparisons prefer opposite poles.

A failure of the two-pole ordering test must contain opposite preferences in at least one of these three pairs of tests:

Pair of comparisons Geometric issue
G0,G1G_0,G_1 The two internal endpoint orderings prefer opposite poles
G0,G2G_0,G_2 The first ordering conflicts with keeping the last receiver short
G1,G2G_1,G_2 The second ordering conflicts with keeping the last receiver short

These are three possible obstruction types, not three proved-realizable metric families or percentages of proof completion. They may overlap. For four inward patches the same theorem uses four comparisons, leaving six possible pairs of opposing preferences.

The adjacent-two-patch proof already resolves the corresponding two-test conflict for a run of length two. Extending that pocket-and-disk repair through one more patch is a concrete next target.

5. Exact examples and limits

Exact applications cover one three-inward and two four-inward shapes, all with both pole curvatures below π\pi. The poles are displaced from a common perpendicular line, so these examples also go beyond the aligned-pole family. They verify the ordering inequalities and independently check all 45 face pairs for three- and four-inward examples. The replay checker uses rational angle bounds. The proof covers every realization satisfying the displayed inequalities; it does not infer a universal pole-choice theorem from successful examples or from searches that found no failure.
