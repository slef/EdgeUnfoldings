# Preserved first face-cap draft

This version restricted the fan curvature to at most pi. It is correct but
was simplified further by orienting the source toward the sharper end of
an opposite pair and choosing the larger curvature difference. The main
OCTA_FACE_CAP_RULE.md and octa_face_caps.py contain the newer rule. These
proof, code, tests and nine certificate domains preserve the first draft.
The copied Python files are reference text, not part of the active suite.
